# Faris Abu Wathlan — Portfolio

Static bilingual portfolio prepared for GitHub Pages.

## Publish
1. Create a GitHub repository and upload the contents of this folder to its root.
2. In the repository, open **Settings → Pages**.
3. Set the deployment source to **Deploy from a branch**, select `main` and `/(root)`, then save.
4. GitHub Pages will show the public URL after the first deployment completes.
